# Чек-лист проверки климатического режима и метаданных записи

Автоматические тесты покрывают резолвер климатического режима, SQL каталога и логику формирования заголовка. Поведение, зависящее от рабочей базы PostgreSQL и реальных окон WinForms, проверяется вручную по этому чек-листу. Каждый пункт, который не удалось выполнить, нужно зафиксировать отдельно, а не отмечать как пройденный.

## Проверка на рабочей базе (вручную)

1. Открыть «Из БД…» — в таблице видна колонка «Режим» между «Эксперимент» и «Длительность, ч».
2. У прогонов Post B и Post C за 2026-08-06 в колонке стоит `32/65`.
3. У прогонов за 2026-08-04 в колонке стоит `25/60`.
4. Подсказка на ячейке режима у прогона с заполненным `climate_mode` — «Из карточки прогона».
5. Подсказка на ячейке режима у прогона без `climate_mode` — «Определён по T-sie: … °C, UR-sie: … %».
6. Фильтры по посту, датам, эксперименту и названию работают как раньше.
7. Список из ~200 прогонов открывается без заметной задержки (ориентир — доли секунды).
8. Открыть один прогон — в заголовке окна графика видно `Название · Модель · Компрессор · Эксперимент · Режим`, например `Post B 2026-08-06 14-33-12 · LIDER · NPT14RA · FUNC · 32/65`. Напряжение и частота из марки компрессора в имя не попадают.
9. То же имя целиком видно в заголовке окна каналов («Каналы: …») и окна источника — оно не обрезается до одного названия.
10. В списке каналов открытого прогона присутствуют `T-sie` и `UR-sie`.
11. Значения `T-sie` на графике соответствуют показанному режиму.
12. Добавить второй прогон через «Из БД…» — заголовок перечисляет полные имена прогонов через `; `.
13. Открыть папочный источник (DBF) — заголовок остался именем папки, ничего не добавилось.
14. Открыть активную запись (статус «Идёт запись») — живое обновление раз в 30 секунд работает, каналы `T-sie` и `UR-sie` дополняются.
15. Экспорт в шаблон отрабатывает без ошибок на прогоне с общими каналами.
16. Добавить второй прогон через «Из БД…» (как в п. 12), затем убрать первый прогон из сравнения — заголовок показывает имя только оставшегося прогона и не содержит данных удалённого.
